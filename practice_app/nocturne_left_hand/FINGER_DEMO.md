# 新版练习室：键盘上的手指示范

入口：`/nocturne-left-hand/index.html`，键盘上方的「观看手指示范」。无需连接电子琴。原有「听一遍完整动作」仍是本组试听，两者为独立入口。

三维真人手模型入口：同一页面的「体验三维真人手型 · 五音示范」，或直接访问 `/nocturne-left-hand/hand-3d.html`。这是当前用于验证真人手感、连续落指和动作节奏的独立原型，使用本地 `right.glb` 手部网格；二维示范仍作为跟随真实课程数据的备用入口。

必须先启动 `practice_app` 本地服务，再通过 `http://localhost:3721/nocturne-left-hand/index.html` 访问。直接双击磁盘 HTML 会导致模块脚本和课程接口无法加载，表现为空白琴键和无效按钮；页面现已在 `file:` 场景自动跳转到本地网站，并保留曲目等参数。若服务器未运行，请使用仓库的「启动练琴App.bat」启动。

点击后显示位于琴键上的手掌和五根手指，播放连续最多 8 个真实 MIDI 音组。手指落下时变为暖黄色；两组之间抬起并移动到下一组琴键。双手音组分别绘制左右手。停止、Esc、切组或页面隐藏会取消示范；示范不调用评分或进度保存。

动作改进：默认「慢动作」统一拉伸音频和动画时间，倍率至少 2 倍，并使最短音组间隔不少于 1.4 秒；选择「跟随示范 BPM」恢复原速度。按住约占间隔的 55%，其余时间用于平滑抬指移手，落键和释放也有渐变。模型增加独立拇指、不同指长、关节和指甲；手掌位置按实际指号偏移计算，所有手指坐标一起插值，减少换指瞬移。仍为程序绘制的二维教学模型，并非扫描真人手或三维骨骼模型。

实现位于 `public/app.js` 的 `paintDemoHands` 和 `watch-fingers` 点击处理。SVG 是 keyboard 的兄弟节点，位于同一滚动容器；坐标取自真实琴键的 offsetLeft/offsetWidth。模型逐帧更新而非重建整个练习页面。音符与动画均根据 AudioContext.currentTime 对时，以 RAW_EVENTS 的 tick 和 TICKS_PER_QUARTER 换算时间，并使用示范速度滑块的 BPM。

范围：二维慢练模式演示选段开头最多 8 组，连续模式从当前事件开始。指法来自已有自动指法，模型是简化二维示意，不是生物力学仿真。当前事件接口没有每音 Note Off，故按住时长取下一音组间隔与 0.8 拍的较小值；不能声称已经还原原曲每音持续时间。三维原型当前固定为右手 C-D-E-F-G 五音，尚未接入课程或 MIDI，也未覆盖左手和弦。踏板原曲还原和完整三维课程化接入不在本阶段范围内。

验证：打开页面，点击观看手指示范，检查键盘上的完整五指模型及顺序变化；点击停止后重播；切换右手/双手课程；调节速度；检查评分进度未因示范增加。脚本可用 `node --check public/app.js` 检查语法。真实 MIDI 硬件不作为观看示范的前置条件。

三维原型验证：打开三维入口，等待状态变为「模型已加载」，点击「开始示范」观察手掌沿键面移动、手指弯曲和当前音符高亮；可切换慢速和侧面视角。资源许可证见 `public/vendor/HAND-LICENSE.txt` 与 `public/vendor/THREE-LICENSE.txt`。
